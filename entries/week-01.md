# Week 01: Setting up GitHub and building my profile

**Date:** 20 Nov 2026

## 🎯 What I set out to do
- Turn an empty GitHub account into a home for my AI learning
- Understand what GitHub actually is, as a marketer rather than a developer

## 📚 What I learned
- A **repository** (repo) is a project folder that remembers every version of every file
- A **commit** is a saved change, and commits are what fill the green squares on a profile
- A repo named exactly after your username becomes your **profile page**, which is GitHub's version of a landing page
- Profile photos need to be under 1 MB, so I compressed mine and cropped it square for the round frame

## ✅ What worked
- Treating my GitHub profile like a brand asset: positioning line first, proof points second, a clear call to action at the end
- Working with an AI assistant to draft, while I made the final calls on wording

## 🧱 What was hard / what I got stuck on
- The vocabulary. Repo, commit, push, README all sound technical until someone explains them in plain words
- Some steps, like creating a new repo, still had to be done by hand in GitHub

## 💬 Prompt or tool of the week
> Treat my GitHub profile like a landing page. Who is the audience, what should they believe in 10 seconds, and what should they do next?

## 🧠 Marketer's takeaway
*How this applies to brand and marketing work:*
GitHub is a credibility channel most marketers ignore. A profile with real, ongoing work shows you can build with AI, not just talk about it.
